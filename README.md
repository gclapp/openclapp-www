# OpenClapp Website

The landing page for www.openclapp.com — a collection of tools and projects by Geoff Clapp.

## Projects

| Project | Subdomain | Description |
|---------|-----------|-------------|
| REI Scraper | rei.openclapp.com | Provider scraping tool for reproductive endocrinology |
| NYCEats | resy.openclapp.com | Restaurant reservation management system |
| Health Dashboard | geoffhealth.openclapp.com | Personal health tracking dashboard |
| Watch Finder | watchfinder.openclapp.com | Rolex DateJust watch hunting tool |

## Development

This is a static HTML/CSS site hosted on GitHub Pages.

## Deployment

The site is automatically deployed via GitHub Pages when changes are pushed to the main branch.
